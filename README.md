# Torpedo Schedule

Афиша недельного расписания тренировок и афиша составов подгрупп: редактор, SQLite, PNG для родительского чата. Многопользовательский вход: тренер каждой команды со своим паролем, отдельный вход для администратора.

```
backend/ FastAPI + Pydantic + SQLite (API, валидация, JWT-авторизация)
frontend/ HTML + CSS + vanilla JS (ES Modules), без сборки
```


## 1. Что умеет

- **Многопользовательский режим.** Тренер каждой команды выбирает свою команду из списка и входит по паролю. Администратор входит под своим логином и паролем и видит список всех команд.
- **Несколько команд.** Администратор создаёт/редактирует/удаляет команды через админку. У каждой команды свои расписания, группы и составы.
- **Общие площадки.** Список площадок глобальный, редактируется администратором. Используется во всех командах.
- **Типы событий.** Тренировка (лёд/зал), товарищеская игра (с одним или несколькими составами и своим временем для каждого), турнир (может длиться несколько дней).
- **Группы и составы.** Разделение на подгруппы, ввод составов списком, чекбокс «печатать состав в афише».
- **Афиши в PNG.** Расписание и составы скачиваются картинкой для родительского чата.

## 2. Требования

- Python 3.12+
- SQLite (обычно уже стоит; на macOS и Linux встроен, на Windows — [sqlite-tools](https://www.sqlite.org/download.html))
- Любой статический сервер для фронта (`python -m http.server`, `npx serve`, nginx) — `file://` не подходит, ES Modules этого не позволяют

## 3. Переменные окружения

Создайте **`backend/.env`** (файл в `.gitignore`, не коммитьте). Шаблон — в `.env.example`:

| Переменная | Что это |
|---|---|
| `SQLITE_PATH` | путь к файлу базы, по умолчанию `./torpedo.db` |
| `JWT_SECRET` | длинная случайная строка для подписи токенов. **Обязательна.** |
| `JWT_TTL_HOURS` | срок жизни токена в часах, по умолчанию 720 (30 дней) |
| `ADMIN_LOGIN` | логин администратора для первого запуска |
| `ADMIN_PASSWORD` | пароль администратора для первого запуска |
| `CORS_ORIGINS` | адреса фронтенда через запятую, например `http://localhost:8001` |


## 4. Публикация

Нужны **HTTPS на обеих частях** (иначе браузер заблокирует запросы со страницы по https к http-API).

- **Frontend**: обычная статика. Подойдёт любой статический хостинг (Cloudflare Pages, Netlify, GitHub Pages). Папка публикации `frontend/`, сборки нет. Перед публикацией поменяйте `api-base` в `index.html` на адрес бэкенда.
- **Backend**: любой хостинг Python-приложений (Render, Fly.io, Railway или свой VPS). Команда запуска: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`. Переменные окружения задаются в панели хостинга, а не файлом. В `CORS_ORIGINS` впишите адрес фронтенда (с `https://`, без слэша на конце).
- Условия бесплатных тарифов меняются, проверяйте актуальные. Бесплатные инстансы часто «засыпают», и первый запрос после простоя идёт медленно: это нормально.
- Интерактивную документацию FastAPI (`/docs`) лучше закрыть в продакшене.

## 5. Чек-лист приёмки (на реальных устройствах)

Автотесты не видят экран, поэтому это проверяется вручную, на iPhone (Safari) и на компьютере:

1. Вход по токену. Неверный токен даёт повторный запрос.
2. Вопрос про подгруппы, «Да» создаёт четыре пустые группы. Ввод состава через «Вставить список».
3. Подсказка «i» у группы: открывается по тапу, не обрезается краем экрана, не меняет чекбокс.
4. Тренировка: время только по 5 минут, лёд / зал / зал по подгруппам, предупреждение о флорболе только у общего занятия в зале.
5. Товарищеская игра (звезда, жёлтый), турнир (кубок, оранжевый).
6. Сохранить, обновить страницу: данные на месте. Открыть с другого устройства: те же данные.
7. Переход по неделям, копирование прошлой недели.
8. **Скачать расписание PNG и составы PNG.** Смотреть: шрифт Play, иконки (шпагат, клюшка), цвета площадок, отсутствие обрезанных надписей, длинное расписание. На iOS файл может открыться во вкладке, а не скачаться.

## 6. Известные ограничения

- Конфликты расписания (два занятия одновременно на одной площадке) не проверяются.
- Параллельные правки с двух устройств: побеждает последнее сохранение.
- Одна роль и один общий токен. Заменить на настоящую авторизацию можно, не трогая остальной код (всё закрыто одной зависимостью `require_admin`).
- Проверка «группа используется в расписаниях» на сервере идёт по всем неделям, но игроки в расписаниях не фигурируют, только группы.
- Редактирование объявления сделано через `prompt()`.
